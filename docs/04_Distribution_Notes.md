- [ ] Install all dependencies from `requirements-build.txt` on Windows.
- [ ] Run `build_windows.bat`.
- [ ] Confirm `dist/CSVDataQualityLab.exe` exists.
- [ ] Double-click the executable without invoking Python source files.
